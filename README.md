# jQuery Mobile Website

This is a **mobile-friendly interactive website** built using **HTML**, **CSS**, and **jQuery**.  
It showcases:
- A responsive **hamburger menu**
- A **button click** interaction using jQuery
- A **toggle section**
- A basic **form with validation**

---

## 📁 Files Included

| File         | Purpose                             |
|--------------|-------------------------------------|
| `index.html` | The main webpage structure          |
| `styles.css` | Styling for layout & mobile design  |
| `script.js`  | jQuery-powered interactions         |

---

## 📱 Features

✅ Mobile Responsive Layout  
✅ Hamburger Menu for Navigation  
✅ jQuery Button Interaction  
✅ Toggle Visibility Using `.slideToggle()`  
✅ Form Validation with User Feedback
